### 개발자 Tony

#### 🏎️ [Roadster Run: 로드스터를 몰며 보는 이력서](https://roadster-resume.vercel.app)

Tesla Roadster 컨셉의 차를 몰고 해질녘 테스트 트랙을 달리며 제 경력과 프로젝트 15개 스테이지를 보는 3D 웹 게임입니다.
부스터, 길게 눌러 높이 뛰는 점프, 공중 배럴 롤(스러스터 분사)을 지원하고, 표지판에 다가가면 상세 내용이 열립니다.

- 플레이: https://roadster-resume.vercel.app
- 코드: [TaehwanGo/roadster-resume](https://github.com/TaehwanGo/roadster-resume) · Next.js 16 · React 19 · Three.js · TypeScript
